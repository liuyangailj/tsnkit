## 1. Correlation-Aware Flow Partitioning Framework

### 1.1 Problem Formulation and Search Space Reduction

在时间敏感网络（TSN）的大规模联合调度与路由优化中，直接利用深度强化学习（DRL）面临着动作空间呈指数级爆炸的挑战。为了解决这一问题，我们将全局流集合 $\mathcal{F}$ 划分为 $M$ 个近似独立的子组 $\mathcal{G} = \{G_1, G_2, \dots, G_M\}$。流分组的核心目标是：**最大化组内的冲突相关性（使强竞争的流在同一组内由DRL协同解决），同时最小化组间耦合度**。

系统输入包含物理网络拓扑图 $G=(V,E)$ 和待调度的流集合 $\mathcal{F}$。每条流 $f_i \in \mathcal{F}$ 的属性定义为元组 $f_i=\{src, dst, size, period, deadline\}$。

为了限制后续路由决策的巨大搜索空间，并为空间冲突提供先验的度量依据，我们利用 Yen's K-Shortest Paths (KSP) 算法为每条流 $f_i$ 预计算 $K$ 条候选最短路径，记为候选路径集合 $\mathcal{P}_i = \{p_i^1, p_i^2, \dots, p_i^K\}$。在后续的调度过程中，流的最终路由仅能在其候选路径集中选取。

### 1.2 Flow Conflict Graph and Spatial Conflict Probability

我们将流之间的空间潜在竞争关系建模为无向的**流冲突图 (Flow Conflict Graph)** $\mathcal{G}_{flow} = (\mathcal{V}_F, \mathcal{E}_F)$。图中每个节点代表一条流 $f_i$，其节点特征向量 $\mathbf{x}_i \in \mathbb{R}^3$ 由归一化后的流属性 $[size, \log(period+1), \log(deadline+1)]$ 组成。若两条流 $f_i$ 和 $f_j$ 的候选路径集合存在物理链路重叠，则在它们之间建立一条无向边 $(i, j) \in \mathcal{E}_F$。

为了精确量化空间竞争的激烈程度，我们定义了**空间冲突概率 (Spatial Conflict Probability)** $e_{ij} \in [0,1]$。其计算方式为：在两流各自的 $K$ 条候选路径组合（共 $K \times K$ 种）中，发生物理链路重叠的组合比例：

$$e_{ij} = \frac{1}{K^2} \sum_{m=1}^K \sum_{n=1}^K \mathbb{I}(p_i^m \cap p_j^n \neq \emptyset)$$

其中 $\mathbb{I}(\cdot)$ 为指示函数。$e_{ij}$ 越大，说明在未来的路由分配中，这两条流发生资源争抢的概率越高。

### 1.3 Topology Reconstruction via Graph Attention Networks

为了捕捉流冲突图中高阶、级联的拓扑依赖关系，我们采用**图注意力网络 (Graph Attention Network, GAT)** 作为编码器，提取包含全局空间冲突结构的节点表征（Embedding） $\mathbf{u}_i$。

与传统的 GAT 不同，我们在特征传播中不仅聚合邻居信息，还将边特征（即空间冲突概率 $e_{ij}$）显式注入到注意力机制中：

$$c_{ij} = \text{LeakyReLU}\left( \mathbf{a}^T [ \mathbf{z}_i^{(l)} \, \| \, \mathbf{z}_j^{(l)} \, \| \, \mathbf{W}_e e_{ij} ] \right)$$

$$\alpha_{ij} = \frac{\exp(c_{ij})}{\sum_{k \in \mathcal{N}_i} \exp(c_{ik})}$$

$$\mathbf{z}_i^{(l+1)} = \text{ELU} \left( \sum_{j \in \mathcal{N}_i} \alpha_{ij} \mathbf{W}^{(l)} \mathbf{z}_j^{(l)} \right)$$

这种设计使得注意力权重 $\alpha_{ij}$ 能够直接受到两流潜在空间冲突强度的调节。网络默认采用多头注意力机制（如 $heads=4$），并在隐藏层设置特征维度为 $d_{hidden}=16$。经过 $L$ 层聚合后，模型输出低维、稠密的流嵌入表示 $\mathbf{u}_i \in \mathbb{R}^{d_{hidden}}$。

**训练目标与几何度量设计：** 我们采用自监督的拓扑重构（Topology Reconstruction）方式来训练 GAT。为了与下游的聚类算法（基于欧氏或余弦几何距离）保持高度兼容，我们**摒弃了基于多层感知机（MLP）的非对称打分，转而采用余弦相似度（Cosine Similarity）作为表征距离度量**。余弦相似度不仅天然满足无向图中流冲突的对称性约束，且作为无参数（Parameter-free）操作，能够迫使 GAT 内部网络学习到泛化能力更强的拓扑特征，避免模型过拟合。

我们将预测相似度通过线性映射至 $[0,1]$ 区间：$\hat{y}_{ij} = (\text{sim}_{cos}(\mathbf{u}_i, \mathbf{u}_j) + 1) / 2$。随后使用加权二元交叉熵 (Weighted BCE) 损失函数进行训练，并引入比例为 $1:1$ 的负采样机制推开无冲突的节点：

$$\mathcal{L}_{self} = - \mathbb{E}_{(i,j) \sim P_{pos}} \left[ e_{ij} \log(\hat{y}_{ij}) + (1 - e_{ij}) \log(1 - \hat{y}_{ij}) \right] - \mathbb{E}_{(i,n) \sim P_{neg}} \log(1 - \hat{y}_{in})$$

### 1.4 Knowledge Fusion and Normalized Spectral Clustering

GAT 编码器精准捕捉了“空间维度”的复杂冲突概率，而 TSN 流同样具备极强的“时间维度”周期规律。为了弥补时域先验，我们引入了基于谐波对齐 (Harmonic Alignment) 的时间亲和度度量 $s_{prior}$：

$$s_{prior}(i, j) = \frac{\text{GCD}(T_i, T_j)}{\text{LCM}(T_i, T_j)}$$

该先验明确了：两流的周期越同步（互为整数倍），它们在超周期内发生排队碰撞的频率越高，应优先分配至同组。

在模型推理阶段，我们将数据驱动生成的归一化空间相似度 $s_{gnn}(i,j) = \hat{y}_{ij}$ 与时间谐波先验 $s_{prior}(i,j)$ 结合，构建混合亲和度矩阵 $\mathbf{W}$：

$$W_{ij} = \alpha \cdot s_{gnn}(i, j) + (1 - \alpha) \cdot s_{prior}(i, j)$$

其中 $\alpha \in [0, 1]$ 为平衡因子（实验中经验性地设置为 $\alpha=0.6$）。

最后，我们对 $\mathbf{W}$ 执行归一化谱聚类 (Normalized Spectral Clustering)。通过计算归一化拉普拉斯矩阵 $L_{sym} = I - D^{-1/2} W D^{-1/2}$ 的前 $k$ 个特征向量形成降维空间 $\mathbf{U}$，并对 $\mathbf{U}$ 的行向量应用 K-Means 算法，最终为每一条流生成分组标签 $C_i \in \{1, \dots, M\}$。分组数 $M$ 可通过拉普拉斯矩阵的特征间隙（Eigengap）启发式确定或根据网络规模静态指定（如 $M=4$）。

## 2. 核心符号表 (Notation Table)

|**Symbol**|**Definition**|
|---|---|
|$\mathcal{F}, f_i$|Global flow set and the $i$-th flow|
|$G=(V, E)$|Physical network topology|
|$\mathcal{P}_i, K$|Set of candidate paths for flow $i$, and the parameter of KSP|
|$\mathcal{G}_{flow}, \mathcal{E}_{F}$|Flow conflict graph and its edge set|
|$e_{ij}$|Spatial conflict probability between flow $i$ and flow $j$|
|$\mathbf{u}_i, \hat{y}_{ij}$|GAT output embedding for flow $i$, and predicted geometric similarity|
|$s_{prior}, s_{gnn}$|Harmonic prior score and GNN-predicted spatial similarity score|
|$\mathbf{W}, \mathbf{U}$|Fusion affinity matrix and Spectral embedding matrix|
|$M, C_i$|Number of flow groups and the assigned group index for flow $i$|

## 3. 算法伪代码 (Algorithm 1)

**Algorithm 1:** Correlation-Aware Flow Partitioning via GAT and Spectral Clustering
**Input:** Global flow set $\mathcal{F}$, Physical topology $G$, KSP parameter $K$, Number of groups $M$, Weight parameter $\alpha$.
**Output:** Ordered Sub-groups $\{G_1, G_2, \dots, G_M\}$ and Node Embeddings $\mathbf{U}_{GAT}$.
1: **Initialization:** $\mathcal{P} \leftarrow \emptyset$, $\mathcal{E}_F \leftarrow \emptyset$, $\mathbf{W} \leftarrow \mathbf{0}^{|\mathcal{F}| \times |\mathcal{F}|}$
2: **for** each flow $f_i \in \mathcal{F}$ **do**
3: $\quad$ Compute top-$K$ shortest paths $\mathcal{P}_i = \{p_i^1, \dots, p_i^K\}$ over $G$ using Yen's Algorithm
4: $\quad$ Construct normalized node features $\mathbf{x}_i \leftarrow [\text{size}_i, \log(T_i+1), \log(D_i+1)]$
5: **end for**
6: **for** pair $(f_i, f_j)$ in $\mathcal{F}$ **do**
7: $\quad$ Compute spatial conflict probability $e_{ij} \leftarrow \frac{1}{K^2} \sum \mathbb{I}(p_i^m \cap p_j^n \neq \emptyset)$
8: $\quad$ **if** $e_{ij} > 0$ **then** add edge $(i, j)$ to $\mathcal{E}_F$ with weight $e_{ij}$
9: **end for**
10: Build Flow Conflict Graph $\mathcal{G}_{flow} = (\mathcal{X}, \mathcal{E}_F)$
11: **GAT Spatial Learning:**
12: **if** model is training **then**
13: $\quad$ Update GAT weights using BCE loss supervised by $e_{ij}$ and Cosine Similarity
14: **end if**
15: Obtain topology-aware embeddings $\mathbf{U}_{GAT} \leftarrow \text{GAT}(\mathcal{G}_{flow})$
16: **Metric Fusion & Clustering (Inference):**
17: **for** pair $(f_i, f_j)$ in $\mathcal{F}$ **do**
18: $\quad$ $s_{gnn} \leftarrow (\text{cosine\_sim}(\mathbf{u}_i, \mathbf{u}_j) + 1) / 2$
19: $\quad$ $s_{prior} \leftarrow \text{GCD}(T_i, T_j) / \text{LCM}(T_i, T_j)$
20: $\quad$ $W_{ij} \leftarrow \alpha \cdot s_{gnn} + (1 - \alpha) \cdot s_{prior}$
21: **end for**
22: Compute Normalized Laplacian $L_{sym} \leftarrow I - D^{-1/2} W D^{-1/2}$
23: Extract spectral embedding matrix $\mathbf{U} \in \mathbb{R}^{|\mathcal{F}| \times M}$ from $L_{sym}$
24: Group assignments $\mathcal{C} \leftarrow \text{KMeans}(\mathbf{U}, \text{clusters}=M)$
25: **return** Partitioned groups based on $\mathcal{C}$, and $\mathbf{U}_{GAT}$ for downstream DRL
